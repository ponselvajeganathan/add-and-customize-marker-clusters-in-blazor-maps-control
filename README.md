# How to Customize Marker Clusters in the Blazor Maps Control

This project is a quick start Blazor WebAssembly application that demonstrates how to add and customize marker clusters using the Syncfusion Blazor Maps component. It focuses on configuring marker clustering, applying templates, and working with multiple marker groups on a map. The sample helps developers understand how clustering improves map visualization when dealing with large sets of markers.

## Project Overview

The application showcases practical usage of the Syncfusion Blazor Maps control by enabling marker clustering to improve performance and visual clarity. It provides examples of how clustered markers behave at different zoom levels and how templates can be applied to customize their appearance. This project is intended as a learning reference for developers building interactive map-based applications with Blazor.

## Features

- Enable marker clustering in the Syncfusion Blazor Maps component  
- Customize marker cluster appearance using templates  
- Display and manage multiple marker groups  
- Demonstrate cluster behavior while zooming and panning the map  
- Built using Blazor WebAssembly  

## Prerequisites

Before running this project, ensure you have the following installed:

- Visual Studio 2022  
- .NET SDK compatible with Blazor WebAssembly  
- Basic knowledge of Blazor and C#  

## How to Run the Project

1. Clone or download this project to a location on your local machine.  
2. Open the solution file in **Visual Studio 2022**.  
3. Restore required NuGet packages by rebuilding the solution.  
4. Run the project using the built-in development server.  

## Usage

Once the application is running, the map will display markers that automatically form clusters based on zoom level. Zooming in reveals individual markers, while zooming out groups them into clusters. Marker templates demonstrate how cluster visuals can be customized for better clarity and user experience.
