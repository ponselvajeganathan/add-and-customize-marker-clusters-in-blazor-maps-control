# How to Customize Marker Clusters in the Blazor Maps Control

## Overview

This sample demonstrates marker clustering and marker-template customization using the Syncfusion [Blazor Maps](https://www.syncfusion.com/blazor-components/blazor-map) component in a hosted Blazor WebAssembly application. The implementation shows how large collections of geographic markers can be grouped into clusters to improve readability and performance when multiple markers overlap in the same region. The sample also demonstrates marker templates, multiple marker groups, and customization techniques that help present location data more effectively within interactive map visualizations.

**Examples**: 

https://blazor.syncfusion.com/demos/maps/marker-template?theme=bootstrap5

https://blazor.syncfusion.com/demos/maps/marker-cluster?theme=bootstrap5

**Documentation**:

https://help.syncfusion.com/chart-sdk/blazor/maps/markers#adding-marker-template

https://help.syncfusion.com/chart-sdk/blazor/maps/markers#marker-clustering

## Key Features

- Demonstrates marker clustering using the Syncfusion Maps marker feature.
- Shows how marker clusters can be enabled to group nearby markers automatically.
- Demonstrates customization of cluster appearance for improved visualization.
- Illustrates the use of marker templates to render custom marker content.
- Demonstrates rendering multiple marker groups within the same map layer.
- Shows how clustered markers help reduce visual overlap in dense geographic regions.
- Demonstrates marker-based location visualization using grouped data points.
- Uses Maps marker functionality to improve map readability and navigation.

## How to Run the Project

**Visual Studio 2022**

1. Clone or download this repository.
2. Open the solution file:

   `CustomizeMarkCluster.sln`

3. Restore NuGet packages.
4. Set the startup project 
5. Build the solution.
6. Run the application using `Ctrl+F5`.

**Visual Studio Code**

1. Open the repository folder in Visual Studio Code.
2. Open the integrated terminal.
3. Navigate to the repository root or startup project directory.

```bash
dotnet restore
dotnet run
```
